# 📦 حزمة إعادة تصميم الـ Embeds — Apostado-Play Bot

> **الهدف:** هذه حزمة كاملة (شرح + بيانات + برومبت) لتسليمها لذكاء اصطناعي آخر (أو مصمم) لإعادة تصميم **كل** رسائل و embeds البوت بشكل **أبسط وأجمل وأوضح**، ثم يعيد لك ملف ZIP بالنتيجة، وأنت تعطيني إياه لأطبّق التعديلات في الكود مباشرةً.

---

## 🚀 كيف تستخدم الحزمة (3 خطوات)

1. **سلّم الذكاء الآخر** هذا المجلد كاملاً (أو ملف الـ ZIP).
2. **ألصق له البرومبت** الموجود في `01_PROMPT_FOR_AI.md` (انسخه كما هو).
3. اطلب منه أن يعيد النتيجة **كمجلد باسم `REDESIGN_OUTPUT/`** بنفس الهيكل الموصوف في `07_expected_output/00_OUTPUT_CONTRACT.md`، ثم اضغطه ZIP وأرجعه لي.

عندما تعطيني ناتج الذكاء الآخر، سأطبّق التصاميم الجديدة على القوالب في الكود واحداً واحداً (باستخدام معرّفات `EMB-001 … EMB-168`) وأرفع التعديلات.

---

## 🧭 ما هو البوت؟ (سياق كامل)

**Apostado-Play** هو بوت ديسكورد لإدارة **ماتشات Free Fire** ومجتمع تنافسي، بلغة **عربية/إنجليزية** مختلطة، مبني على `discord.py 2.x`. يدير:

| المجال | الوصف |
|---|---|
| **تدفّق اللعب** | إنشاء لوبي (`!!play4v4` … `!!play1v1`)، غرف انتظار صوتية، انضمام للفرق، بدء الماتش، إلغاء بلوبي |
| **التصويت الجماعي على MVP** | مصوّرون (أول 2 من كل فريق) يصوّتون لأفضل لاعب فائز/خاسر، مع تصعيد للأدمن عند عدم الاتفاق |
| **نتيجة الماتش** | إعلان الفائزين + النقاط، وتُرسَل إلى قناة `match-results` |
| **البروفايل والرانك** | `!!p` / `!!card`، نقاط، رانك، MVPs، Top 10 leaderboard |
| **البلاغات والحظر** | `!!report`، فويسات التفتيش، `!!banplayer` |
| **السجن (JAIL)** | `!!jail` / `!!unjail` |
| **البلاك ليست (BLACKLIST)** | حظر مؤقت 10 دقائق، قناة `🔇・Blacklisted` |
| **أوامر الأدمن** | Setup، Autosetup، Scan، Ranks، Roles، نقاط، Cloud |

## 🗂️ كيف تُقرأ البيانات (دليل المصطلحات)

كل قالب له **معرّف ثابت** `EMB-001 … EMB-168` مرتبط بـ:
- `line` → رقم السطر في `freefire-bot-main.py` (موقعه في الكود).
- `func` → الدالة/التدفق الذي ينتمي إليه (مثلاً `create_lobby_embed`, `notify_admins`, `report_cmd`).
- `embed` → نص `discord.Embed(...)` الحرفي.
- `modifiers` → سلاسل `.add_field` / `.set_footer` / `.set_author` المرتبطة.
- `sends` → نداء الإرسال (`channel.send(embed=...)`) الذي يوضّح الوجهة والأزرار.

**مصطلحات في الكتالوج:**
- `ephemeral: True` = رسالة تُرى فقط للمستخدم الذي نفّذ الأمر (تختفي).
- `delete_after=N` = تُحذف تلقائياً بعد N ثانية.
- `view=` = الأزرار/القوائم المرفقة بالرسالة.
- **Dead code**: `VoteView` و `MvpSelectionView` تدفقات قديمة غير مُستدعاة — يمكن تجاهلها أو تحسينها كنموذج.

## ✅ ملاحظات مهمة قبل التسليم

- البوت **ثنائي اللغة**: حافظ على العربية عربية والإنجليزية إنجليزية، مع دعم RTL.
- **لا تحذف أي معلومة أو حقل** — إعادة تصميم بصري فقط (لا تغيير في الوظائف أو الأزرار).
- حدود ديسكورد (title ≤ 256، description ≤ 4096، قيمة الحقل ≤ 1024، ≤ 25 حقلاً…) مذكورة في البرومبت.
- **بدون صور/GIF** للحفاظ على الأداء والاعتمادية (استخدم الإيموجي كأيقونات).
